# GitHub Pages

This directory contains the static GitHub Pages site for `jrrembert/skills`.

To publish it:

1. Open the repository settings on GitHub.
2. Go to **Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Choose the `main` branch and `/docs` folder.
5. Save.

GitHub will serve the site at:

```text
https://jrrembert.github.io/skills/
```
