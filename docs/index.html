Skills

The repo currently ships one focused skill, with the structure ready for more skills as the collection grows.

Goal Decomposer

Decomposes a big idea, ambition, or vague life direction into a two-week sprint with a theme, concrete work and personal goals, and lightweight accountability.

Best for

Sabbaticals, between-jobs periods, side projects, freelancing, and other self-directed phases where structure is missing.

Outputs

Sprint dates, a theme, 4-6 goals across work and personal life, and reusable accountability email templates.

Evals

The repo includes runnable regression evals so skills can be compared against a baseline and checked for structural quality.

Deterministic checks

Parsed outputs are checked for goal counts, work/personal split, theme presence, and accountability setup.

Blind comparison

A judge compares with-skill and baseline responses across qualitative dimensions defined per skill.
